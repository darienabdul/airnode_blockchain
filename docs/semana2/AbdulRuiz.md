## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

1. Como técnico de mantenimiento, quiero registrar una intervención realizada para que quede asociada a mi identidad, fecha y trabajo ejecutado.
2. Como técnico de mantenimiento, quiero consultar el historial de intervenciones de una aeronave o componente para conocer los trabajos realizados anteriormente.
3. Como técnico de mantenimiento, quiero adjuntar las evidencias relacionadas con una intervención para que el registro contenga la información necesaria para demostrar el trabajo realizado.
4. Como técnico de mantenimiento, quiero registrar una corrección o modificación sobre una intervención anterior para que quede evidencia de qué cambió y cuándo ocurrió.
5. Como auditor, quiero consultar el historial completo de una aeronave o componente para poder reconstruir las intervenciones realizadas.
6. Como auditor, quiero verificar quién realizó cada intervención y cuándo fue registrada para poder comprobar la atribución de las actividades.
7. Como auditor, quiero verificar la integridad y secuencia de los registros para poder identificar modificaciones posteriores o inconsistencias en el historial.
